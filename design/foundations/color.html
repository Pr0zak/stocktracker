Colour

Two families that must never blur into each other. Semantic says the market moved and is only ever green or red. System says this app has an opinion and is always amber. A dip tier rendered on the price scale would read as “it went up today”, which is the opposite of the truth for a name down 40%.

Red / green under deuteranopia

the recurring risk

Roughly 8% of men cannot separate these two hues. The app is already careful — every change carries ▲/▼ and a sign, so direction survives without colour. The failures have all been in charts, where the arrow has nowhere to live and shape has to do the work instead. Simulated below: the same two lines, then the same pair as shipped now.

VIX severity ramp

its own family

Inverted against every other scale in the app: a HIGH reading is the bad end. Five fixed bands rather than a gradient, so they can be counted, plus boundary values and a pointer — position is readable numerically when the hues won't separate.

Rules

  1. Colour is never the only channel. Direction gets an arrow and a sign; a chart line gets a dash pattern; a band gets a boundary value.
  2. Semantic and system never mix. A tile carries which scale it is on, so a dip tier cannot be rendered as a good day.
  3. Absent is not flat. Data we could not load renders as amber and says so — it never borrows the neutral that means “genuinely unchanged”.
  4. References are neutral. A benchmark, a cost line, a previous close: grey and dashed. Spending gain/loss on them makes a comparison look like a verdict.

Why this sheet exists. Every colour bug found in this app has been the same shape — a value that was absent or reference rendered through a path written for present or semantic. The palette is small on purpose; the discipline is in which family a thing belongs to, not in how many hues are available. Open question: the VIX ramp shares hues with the dip-tier amber. They never appear on the same surface today, but if they ever do, the VIX bands should get tick marks rather than a re-hue — the green-to-red convention is load-bearing for a fear gauge.
